# Aula Arduino

Sitio educativo interactivo para que estudiantes de Segundo Año de Bachillerato estudien y repasen Arduino, sensores, automatización, robótica y diseño 3D.

## Sitio publicado

https://kelvinariel.github.io/aula-arduino/

## Contenido

- 22 guías organizadas por semana.
- 19 ejemplos de código Arduino (`.ino`).
- Buscador, filtros, favoritos y seguimiento de progreso en el navegador.
- 66 preguntas de autoevaluación y 30 actividades prácticas.
- Mini laboratorio interactivo.

Los documentos de planificación docente no forman parte de este repositorio. El contenido fue adaptado como material de estudio dirigido al alumnado.

## Estructura

- `index.html`: entrada principal.
- `styles.css`: estilos responsivos.
- `app.js`: interfaz e interacciones.
- `curriculum.js`: contenido de las 22 semanas.
- `codes.js`: ejemplos mostrados dentro del sitio.
- `guias/`: guías HTML descargables.
- `codigos/`: archivos Arduino descargables.

## Publicación con GitHub Pages

El proyecto es completamente estático. En GitHub, abre **Settings → Pages**, selecciona **Deploy from a branch**, usa la rama `main` y la carpeta raíz `/`.
