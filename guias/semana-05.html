Potenciómetro y control de intensidad

Convierte un giro en brillo, niveles o tiempos.

¿Qué aprenderás?

  • Identificar los tres terminales del potenciómetro.
  • Transformar 0–1023 en 0–255.
  • Aplicar una entrada variable a diferentes proyectos.

Un divisor que puedes ajustar

El potenciómetro tiene dos extremos y un cursor central. Con los extremos conectados a 5 V y GND, el cursor entrega un voltaje variable que Arduino puede leer. Si intercambias los extremos, cambia el sentido del giro respecto a la lectura.

De la lectura al brillo

analogRead(A0) obtiene un valor de 0 a 1023. map(lectura, 0, 1023, 0, 255) produce un valor apropiado para PWM. Conecta el LED a un pin marcado con ~ en el UNO R3; D9 funciona en este ejemplo sin biblioteca Servo.

Una misma entrada, distintas decisiones

En un semáforo, el potenciómetro puede ajustar el tiempo de una fase. En una barra de LEDs, selecciona cuántos se encienden. Al combinarlo con LDR, puede ajustar la sensibilidad del sistema. Escribe claramente qué representa el valor en cada aplicación.

Prácticas

Regulador de brillo

  1. Conecta el cursor a A0 y el LED con su resistencia a D9.
  2. Carga el ejemplo y gira desde un extremo hasta el otro.
  3. Anota lectura y PWM en los extremos y en el centro.

Resultado esperado: El brillo cambia progresivamente con el giro.

Tres retos de control

  1. Diseña un semáforo cuyo tiempo varíe con el giro.
  2. Divide el intervalo en tres niveles para una barra de LEDs.
  3. Usa el potenciómetro como umbral para comparar la lectura de una LDR.

Resultado esperado: Tres reglas distintas de transformación y una tabla de pruebas para cada una.

Ten en cuenta: PWM regula el tiempo de encendido de pulsos; no convierte un pin del UNO R3 en una salida de voltaje analógico continuo.

Código Arduino

// Potenciometro: extremos a 5V y GND, cursor a A0.
const int pinPot = A0, pinLED = 9;
void setup() {
  pinMode(pinLED, OUTPUT);
  Serial.begin(9600);
}
void loop() {
  int lectura = analogRead(pinPot);
  int brillo = map(lectura, 0, 1023, 0, 255);
  analogWrite(pinLED, brillo);
  Serial.print("Entrada: "); Serial.print(lectura);
  Serial.print(" | PWM: "); Serial.println(brillo);
  delay(100);
}

Preguntas de repaso

1. ¿Qué terminal se conecta a la entrada analógica?

  1. El cursor central
  2. Los tres juntos
  3. Solo GND

2. ¿Qué función transforma intervalos?

  1. pinMode()
  2. map()
  3. Serial.begin()

3. ¿Cuál sirve como pin PWM en UNO R3?

  1. D8
  2. D9
  3. D12

Respuestas explicadas

1. El cursor central. El cursor toma una fracción del voltaje entre los extremos.

2. map(). map() convierte un valor de un intervalo en otro.

3. D9. D9 es uno de los pines PWM del UNO R3.
