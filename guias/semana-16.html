Estacionamiento con avisos de proximidad

Clasifica distancias y cambia la frecuencia de los avisos.

¿Qué aprenderás?

  • Clasificar tres zonas de distancia.
  • Distinguir tono y repetición del aviso.
  • Tratar el error de lectura de forma explícita.

Distancia convertida en señal

Más de 100 cm representa zona lejana, más de 30 y hasta 100 cm precaución, y 30 cm o menos proximidad alta. Un LED por estado permite reconocer la decisión.

Comunicación sonora

El tono es la frecuencia del sonido; la repetición es cada cuánto se oye. El ejemplo utiliza avisos más rápidos al acercarse. Estos sonidos comunican categorías; no miden por sí mismos la velocidad de un vehículo.

Distinguir error de distancia

Si no llega un eco, el código adaptado apaga los indicadores de distancia y presenta un tono de error. No asigna al fallo una distancia artificial que pueda confundirse con una zona libre.

Prácticas

Asistente de estacionamiento

  1. Arma el circuito y observa las zonas en Serial.
  2. Prueba 150, 60 y 20 cm; compara color y ritmo del sonido.
  3. Comprueba el tratamiento de una medición inválida.

Resultado esperado: Tres zonas claramente diferenciadas y un estado de error independiente.

Código Arduino

const int pinTrig = 9;
const int pinEcho = 10;
const int ledVerde = 4;
const int ledAmarillo = 5;
const int ledRojo = 6;
const int buzzer = 8;
void activarLuces(int verde, int amarillo, int rojo);
void setup() {
  pinMode(pinTrig, OUTPUT);
  pinMode(pinEcho, INPUT);
  pinMode(ledVerde, OUTPUT);
  pinMode(ledAmarillo, OUTPUT);
  pinMode(ledRojo, OUTPUT);
  pinMode(buzzer, OUTPUT);
  Serial.begin(9600);
}
void loop() {
  digitalWrite(pinTrig, LOW);
  delayMicroseconds(2);
  digitalWrite(pinTrig, HIGH);
  delayMicroseconds(10);
  digitalWrite(pinTrig, LOW);
  long duracion = pulseIn(pinEcho, HIGH, 30000);
  float distancia;
  if (duracion == 0) {
    activarLuces(LOW, LOW, LOW);
    tone(buzzer, 300);
    Serial.println("ERROR: sin eco valido");
    delay(300);
    return;
  }
  distancia = duracion * 0.0343 / 2.0;
  if (distancia <= 30.0) {
    activarLuces(LOW, LOW, HIGH);
    tone(buzzer, 1200);
    Serial.print("PELIGRO");
    delay(150);
    noTone(buzzer);
    delay(150);
  } else if (distancia <= 100.0) {
    activarLuces(LOW, HIGH, LOW);
    tone(buzzer, 700);
    Serial.print("PRECAUCION");
    delay(100);
    noTone(buzzer);
    delay(500);
  } else {
    activarLuces(HIGH, LOW, LOW);
    noTone(buzzer);
    Serial.print("ZONA SEGURA");
    delay(300);
  }
  Serial.print(" | Distancia: ");
  Serial.print(distancia, 1);
  Serial.println(" cm");
}
void activarLuces(int verde, int amarillo, int rojo) {
  digitalWrite(ledVerde, verde);
  digitalWrite(ledAmarillo, amarillo);
  digitalWrite(ledRojo, rojo);
}

Preguntas de repaso

1. ¿Qué zona corresponde a 60 cm?

  1. Lejana
  2. Precaución
  3. Lectura inválida

2. ¿Qué cambia al acercarse el objeto?

  1. El aviso se repite más rápido
  2. El sensor se convierte en PIR
  3. El programa deja de medir para siempre

3. ¿Qué significa que no llegó eco antes del tiempo límite?

  1. Camino libre confirmado
  2. No hay una distancia válida
  3. Objeto a exactamente 999 cm

Respuestas explicadas

1. Precaución. 60 se encuentra por encima de 30 y hasta 100 cm.

2. El aviso se repite más rápido. El ritmo sonoro permite comunicar mayor proximidad.

3. No hay una distancia válida. Un tiempo de espera agotado debe tratarse como error de medición.
