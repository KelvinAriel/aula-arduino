LDR: la luz como entrada

Lee la iluminación y construye una respuesta automática.

¿Qué aprenderás?

  • Explicar cómo cambia la resistencia de una LDR.
  • Construir un divisor de tensión.
  • Calibrar un umbral de iluminación.

La LDR cambia su resistencia

Una fotorresistencia o LDR disminuye normalmente su resistencia al recibir más luz. Arduino mide el voltaje de un circuito, por eso se combina con una resistencia fija para formar un divisor de tensión.

La orientación importa

En el montaje de este sitio, conecta 5 V → LDR → nodo A0 → resistencia de 10 kΩ → GND. Con esa orientación, la lectura aumenta con la luz. Si intercambias la LDR y la resistencia, la tendencia se invierte y debes adaptar la condición.

Calibrar y comprobar

Observa primero las lecturas con luz y oscuridad en el Monitor Serial. Escoge un umbral entre ambos valores; no existe un número universal que funcione en cualquier ambiente. La práctica se amplía relacionando sensores con una alarma de habitación o un ventilador automático.

Prácticas

Lámpara automática

  1. Construye el divisor de tensión y conecta un LED con resistencia de 220 Ω a D9.
  2. Carga el programa, cambia la luz simulada y anota las lecturas.
  3. Ajusta el umbral y comprueba que el LED se encienda con oscuridad.

Resultado esperado: El LED responde al umbral que calibraste.

Compara aplicaciones

  1. Representa una alarma de habitación con PIR y un ventilador con TMP36.
  2. Para cada uno, escribe entrada, condición y salida.
  3. Consulta las semanas 8 y 10 para reconstruir cada sistema.

Resultado esperado: Distingues el sensor adecuado para luz, movimiento y temperatura.

Código Arduino

// Divisor: 5V -> LDR -> nodo A0 -> 10 kohm -> GND
const int pinLDR = A0, pinLED = 9;
const int umbral = 500; // Ajustar tras observar luz y oscuridad.
void setup() {
  pinMode(pinLED, OUTPUT);
  Serial.begin(9600);
}
void loop() {
  int luz = analogRead(pinLDR);
  digitalWrite(pinLED, luz < umbral ? HIGH : LOW);
  Serial.print("LDR: "); Serial.println(luz);
  delay(200);
}

Preguntas de repaso

1. ¿Qué ocurre normalmente con la resistencia de la LDR al aumentar la luz?

  1. Aumenta siempre
  2. Disminuye
  3. Desaparece físicamente

2. ¿Para qué sirve el divisor de tensión?

  1. Para convertir el cambio de resistencia en un voltaje medible
  2. Para sustituir el código
  3. Para alimentar un motor directamente

3. Si inviertes LDR y resistencia, ¿qué debes revisar?

  1. El nombre del archivo
  2. La tendencia de la lectura y la condición del programa
  3. El color del USB

Respuestas explicadas

1. Disminuye. La fotorresistencia suele ofrecer menos resistencia al recibir más iluminación.

2. Para convertir el cambio de resistencia en un voltaje medible. Arduino lee el voltaje del punto medio del divisor.

3. La tendencia de la lectura y la condición del programa. La relación entre luz y voltaje cambia según la disposición del divisor.
