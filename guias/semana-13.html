Alarma armable con pulsador

Añade memoria de estado y controla cuándo vigilar.

¿Qué aprenderás?

  • Distinguir desarmada, vigilancia y alerta.
  • Usar INPUT_PULLUP.
  • Cambiar estado con una pulsación.

Recordar un estado

Una variable bool almacena si la alarma está armada. El movimiento solo dispara la alerta cuando esa variable es true. Esto diferencia la entrada del sensor del estado interno del sistema.

Un botón activo en LOW

Con INPUT_PULLUP, conecta el pulsador entre D3 y GND. El pin está HIGH sin pulsación y LOW cuando se presiona. No conectes ese botón directamente entre 5 V y GND.

Detectar el cambio y el rebote

Comparar el estado actual con el anterior permite actuar al comenzar la pulsación. El ejemplo añade una pausa sencilla, pero un botón real puede rebotar; una versión más robusta utiliza una ventana de estabilidad con millis().

Prácticas

Activa y desactiva vigilancia

  1. Arma PIR, pulsador, dos LEDs y buzzer.
  2. Inicia desarmada; pulsa una vez y luego simula movimiento.
  3. Mantén el botón presionado y observa si ocurre un solo cambio; vuelve a pulsar para desarmar.

Resultado esperado: Tres estados reconocibles: desarmada, armada sin movimiento y alerta.

Código Arduino

const int pinPIR = 2;
const int pinBoton = 3;
const int ledVerde = 4;
const int ledRojo = 5;
const int pinBuzzer = 8;
bool alarmaArmada = false;
int estadoAnteriorBoton = HIGH;
void setup() {
  pinMode(pinPIR, INPUT);
  pinMode(pinBoton, INPUT_PULLUP);
  pinMode(ledVerde, OUTPUT);
  pinMode(ledRojo, OUTPUT);
  pinMode(pinBuzzer, OUTPUT);
  Serial.begin(9600);
}
void loop() {
  int estadoBoton = digitalRead(pinBoton);
  int movimiento = digitalRead(pinPIR);
  // Cambiar el estado una sola vez al comenzar cada pulsación.
  if (estadoBoton == LOW && estadoAnteriorBoton == HIGH) {
    if (alarmaArmada == true) {
      alarmaArmada = false;
    } else {
      alarmaArmada = true;
    }
    delay(50);
  }
  estadoAnteriorBoton = estadoBoton;
  // Seleccionar uno de los tres estados del sistema.
  if (alarmaArmada == false) {
    digitalWrite(ledVerde, LOW);
    digitalWrite(ledRojo, LOW);
    noTone(pinBuzzer);
    Serial.println("DESARMADA");
  } else if (movimiento == HIGH) {
    digitalWrite(ledVerde, LOW);
    digitalWrite(ledRojo, HIGH);
    tone(pinBuzzer, 1000);
    Serial.println("ALERTA: movimiento detectado");
  } else {
    digitalWrite(ledVerde, HIGH);
    digitalWrite(ledRojo, LOW);
    noTone(pinBuzzer);
    Serial.println("ARMADA: vigilancia activa");
  }
  delay(100);
}

Preguntas de repaso

1. Con INPUT_PULLUP, ¿qué se lee al pulsar un botón conectado a GND?

  1. HIGH
  2. LOW
  3. 255

2. ¿Qué variable representa si se está vigilando?

  1. Una variable booleana de armado
  2. La distancia del sensor
  3. El brillo de pantalla

3. ¿Por qué comparar botón actual y anterior?

  1. Para actuar al inicio de la pulsación
  2. Para medir temperatura
  3. Para evitar GND

Respuestas explicadas

1. LOW. La resistencia interna mantiene HIGH y la pulsación lleva la entrada a tierra.

2. Una variable booleana de armado. El estado de armado se conserva entre iteraciones.

3. Para actuar al inicio de la pulsación. Detectar la transición evita cambiar el estado repetidamente mientras se mantiene pulsado.
