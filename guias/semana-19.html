Robótica: percibir, decidir y actuar

Reconoce los subsistemas y construye un indicador de proximidad.

¿Qué aprenderás?

  • Reconocer estructura, energía, percepción, control y acción.
  • Relacionar una medición con una posición.
  • Distinguir un prototipo didáctico de un robot completo.

Un robot es un sistema

Un sistema robótico coordina estructura, energía, sensores, controlador y actuadores para una tarea. Arduino puede ser el controlador, pero la placa por sí sola no constituye todo el robot.

Percibir y clasificar

El HC-SR04 aporta una medición que el programa clasifica en zona lejana, media o cercana. El LED comunica esa decisión y un servo representa una respuesta mecánica.

Una posición por zona

El prototipo utiliza 0° para más de 100 cm, 90° para más de 30 y hasta 100 cm, y 180° para 30 cm o menos. Ante error mantiene una posición de referencia de 90° y apaga los LEDs. Es una decisión para este indicador, no una regla universal de seguridad.

Prácticas

Indicador robótico de proximidad

  1. Identifica los cinco subsistemas en un dibujo.
  2. Arma sensor, servo y LEDs con la tabla.
  3. Prueba las tres zonas y explica cómo cambia la acción a partir de la percepción.

Resultado esperado: Una simulación que comunica distancia mediante color y ángulo.

Código Arduino

#include <Servo.h>
const int pinTrig = 9;
const int pinEcho = 10;
const int ledVerde = 3;
const int ledAmarillo = 4;
const int ledRojo = 5;
const int pinServo = 6;
Servo indicador;
float medirDistancia() {
  digitalWrite(pinTrig, LOW);
  delayMicroseconds(2);
  digitalWrite(pinTrig, HIGH);
  delayMicroseconds(10);
  digitalWrite(pinTrig, LOW);
  unsigned long duracion = pulseIn(pinEcho, HIGH, 30000);
  if (duracion == 0) return -1.0;
  return duracion * 0.0343 / 2.0;
}
void mostrarEstado(int verde, int amarillo, int rojo, int angulo) {
  digitalWrite(ledVerde, verde);
  digitalWrite(ledAmarillo, amarillo);
  digitalWrite(ledRojo, rojo);
  indicador.write(angulo);
}
void setup() {
  pinMode(pinTrig, OUTPUT);
  pinMode(pinEcho, INPUT);
  pinMode(ledVerde, OUTPUT);
  pinMode(ledAmarillo, OUTPUT);
  pinMode(ledRojo, OUTPUT);
  indicador.attach(pinServo);
  Serial.begin(9600);
}
void loop() {
  float distancia = medirDistancia();
  if (distancia < 0) {
    mostrarEstado(LOW, LOW, LOW, 90);
    Serial.println("Lectura no valida");
  } else if (distancia <= 30) {
    mostrarEstado(LOW, LOW, HIGH, 180);
    Serial.println("Zona cercana");
  } else if (distancia <= 100) {
    mostrarEstado(LOW, HIGH, LOW, 90);
    Serial.println("Zona media");
  } else {
    mostrarEstado(HIGH, LOW, LOW, 0);
    Serial.println("Zona lejana");
  }
  delay(300);
}

Preguntas de repaso

1. ¿Cuál es el controlador de este prototipo?

  1. Arduino UNO
  2. La resistencia del LED
  3. La base de cartón

2. ¿Qué hace el servo a 60 cm?

  1. 0°
  2. 90°
  3. 180°

3. ¿Cuál secuencia describe el funcionamiento?

  1. Actuar, olvidar, borrar
  2. Percibir, decidir, actuar
  3. Imprimir, cortar, pintar

Respuestas explicadas

1. Arduino UNO. Arduino ejecuta las reglas y coordina las salidas.

2. 90°. 60 cm pertenece a la zona media.

3. Percibir, decidir, actuar. Los sensores perciben, el controlador decide y los actuadores responden.
