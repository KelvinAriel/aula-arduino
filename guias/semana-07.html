HC-SR04: medir con un eco

Calcula distancias y analiza una respuesta ante obstáculos.

¿Qué aprenderás?

  • Identificar TRIG y ECHO.
  • Explicar el tiempo de ida y vuelta.
  • Detectar lecturas inválidas antes de decidir.

Emitir y escuchar

El HC-SR04 utiliza una señal de disparo por TRIG y un pulso de respuesta por ECHO. El programa mide la duración del pulso, no la distancia de manera directa. En el ejemplo se envía un disparo de 10 microsegundos.

Tiempo convertido en distancia

La aproximación distancia_cm = duración_us × 0,0343 / 2 usa una velocidad del sonido cercana a condiciones ambientales habituales. La división entre dos corresponde al viaje de ida y regreso. La precisión real depende del entorno, del objeto y del sensor.

Sin eco también es un resultado

pulseIn(..., 30000) limita el tiempo de espera. Si devuelve cero, el ejemplo trata la lectura como inválida. Un robot no debería interpretar automáticamente ausencia de eco como camino libre: debe detener o señalar el error según su diseño.

Prácticas

Detector de proximidad

  1. Conecta el HC-SR04 y los tres LEDs indicados.
  2. Prueba 20, 60 y 150 cm, y observa Serial a 9600.
  3. Explica la respuesta del programa cuando pulseIn devuelve cero.

Resultado esperado: Cada zona tiene un color y el fallo se distingue de una distancia válida.

Diseña un evitador de obstáculos

  1. Dibuja un robot con sensor, controlador, driver y motores.
  2. Define cuándo avanza, se detiene o gira; representa primero esas salidas con LEDs.
  3. Prepara pruebas de obstáculo cercano y lectura inválida antes de añadir movimiento.

Resultado esperado: Un algoritmo verificable; el ejemplo descargable se centra en percepción y señalización.

Código Arduino

// Semaforo de proximidad: el error no se interpreta como camino libre.
const int pinTrig = 9, pinEcho = 10;
const int ledVerde = 4, ledAmarillo = 5, ledRojo = 6;

float medirDistancia() {
  digitalWrite(pinTrig, LOW);
  delayMicroseconds(2);
  digitalWrite(pinTrig, HIGH);
  delayMicroseconds(10);
  digitalWrite(pinTrig, LOW);
  unsigned long duracion = pulseIn(pinEcho, HIGH, 30000);
  if (duracion == 0) return -1.0;
  return duracion * 0.0343 / 2.0;
}
void setup() {
  pinMode(pinTrig, OUTPUT); pinMode(pinEcho, INPUT);
  pinMode(ledVerde, OUTPUT); pinMode(ledAmarillo, OUTPUT);
  pinMode(ledRojo, OUTPUT);
  Serial.begin(9600);
}
void loop() {
  float distancia = medirDistancia();
  bool valida = distancia >= 0;
  digitalWrite(ledRojo, valida && distancia <= 30 ? HIGH : LOW);
  digitalWrite(ledAmarillo, valida && distancia > 30 && distancia <= 100 ? HIGH : LOW);
  digitalWrite(ledVerde, valida && distancia > 100 ? HIGH : LOW);
  if (valida) {
    Serial.print("Distancia (cm): ");
    Serial.println(distancia, 1);
  } else {
    Serial.println("ERROR: sin eco valido");
  }
  delay(300);
}

Preguntas de repaso

1. ¿Para qué se utiliza TRIG?

  1. Enviar el disparo de medición
  2. Alimentar el motor
  3. Mostrar texto

2. ¿Qué mide pulseIn() en este ejemplo?

  1. La duración del pulso ECHO
  2. Los grados del servo
  3. El brillo ambiental

3. ¿Cómo conviene tratar un retorno de cero por tiempo de espera?

  1. Como un objeto exactamente a 0 cm
  2. Como lectura inválida
  3. Como 100 % de luz

Respuestas explicadas

1. Enviar el disparo de medición. TRIG inicia una medición ultrasónica.

2. La duración del pulso ECHO. Devuelve una duración en microsegundos que se convierte en distancia.

3. Como lectura inválida. Sin eco válido no se dispone de una distancia confiable.
