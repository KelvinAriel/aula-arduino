Proyecto: aula inteligente

Iluminación, ventilación y puerta trabajando juntas.

¿Qué aprenderás?

  • Dividir un proyecto en módulos.
  • Integrar tres entradas sin conflictos de pines.
  • Verificar escenarios combinados.

Divide antes de integrar

El aula inteligente contiene iluminación por LDR, ventilación por TMP36 y puerta por PIR. Cada módulo debe tener una entrada, una regla y una salida identificables. Escribe una prueba para cada uno antes de unirlos.

Pines y responsabilidades

A0 lee luz, A1 temperatura y D2 movimiento. D3 controla brillo, D5 motor y D9 el servo. En este ejemplo no se usa tone(), por lo que D3 se mantiene disponible para PWM; añadir funciones puede cambiar la disponibilidad de temporizadores.

Leer, decidir y actuar

loop() procesa los tres módulos en cada iteración y muestra datos por Serial. El ejemplo tiene una pausa breve de 300 ms. Si el proyecto necesita respuesta más rápida, evalúa la frecuencia de lectura y utiliza temporización sin bloqueo.

Prácticas

Construye tu aula inteligente

  1. Prueba cada módulo aislado usando las semanas anteriores.
  2. Integra las conexiones de esta guía y carga el programa.
  3. Combina oscuridad, calor y presencia; después cambia una entrada a la vez.

Resultado esperado: Cada salida responde a su sensor sin alterar indebidamente a las demás.

Código Arduino

#include <Servo.h>
const int pinLdr = A0;
const int pinTmp = A1;
const int pinPir = 2;
const int pinLed = 3;
const int pinMotor = 5;
const int pinServo = 9;
Servo puerta;
void setup() {
  pinMode(pinPir, INPUT);
  pinMode(pinLed, OUTPUT);
  pinMode(pinMotor, OUTPUT);
  puerta.attach(pinServo);
  puerta.write(0);
  Serial.begin(9600);
}
void loop() {
  // Subsistema de iluminación
  int luz = analogRead(pinLdr);
  int brilloLed = map(luz, 0, 1023, 255, 0);
  brilloLed = constrain(brilloLed, 0, 255);
  analogWrite(pinLed, brilloLed);
  // Subsistema de ventilación
  int lecturaTmp = analogRead(pinTmp);
  float voltaje = lecturaTmp * (5.0 / 1023.0);
  float temperatura = (voltaje - 0.5) * 100.0;
  int velocidadMotor;
  if (temperatura < 25.0) {
    velocidadMotor = 0;
  } else if (temperatura <= 30.0) {
    velocidadMotor = 150;
  } else {
    velocidadMotor = 255;
  }
  analogWrite(pinMotor, velocidadMotor);
  // Subsistema de acceso
  int presencia = digitalRead(pinPir);
  if (presencia == HIGH) {
    puerta.write(90);
  } else {
    puerta.write(0);
  }
  // Información para comprobar y depurar
  Serial.print("Luz: ");
  Serial.print(luz);
  Serial.print(" | Brillo: ");
  Serial.print(brilloLed);
  Serial.print(" | Temperatura: ");
  Serial.print(temperatura, 1);
  Serial.print(" C | Motor: ");
  Serial.print(velocidadMotor);
  Serial.print(" | Presencia: ");
  Serial.println(presencia);
  delay(300);
}

Preguntas de repaso

1. ¿A qué pin se conecta el TMP36 en esta semana?

  1. A0
  2. A1
  3. D9

2. ¿Qué significa integrar por módulos?

  1. Conectar todo sin probar
  2. Comprobar cada función y después coordinarla con las demás
  3. Usar un solo cable

3. ¿Por qué revisar temporizadores al añadir bibliotecas?

  1. Pueden compartir recursos usados por salidas PWM
  2. Cambian el color físico de la placa
  3. Aumentan el tamaño de los sensores

Respuestas explicadas

1. A1. A0 se reserva para la LDR y A1 para la temperatura.

2. Comprobar cada función y después coordinarla con las demás. Las pruebas individuales simplifican la depuración del conjunto.

3. Pueden compartir recursos usados por salidas PWM. Algunas funciones y bibliotecas utilizan los mismos temporizadores internos.
