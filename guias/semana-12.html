Iluminación automática con PWM

Aumenta el brillo cuando disminuye la luz ambiental.

¿Qué aprenderás?

  • Representar entrada, proceso y salida.
  • Invertir intervalos con map().
  • Comprobar el brillo en varios niveles.

Automatizar una respuesta

Automatizar consiste en ejecutar reglas para responder a condiciones medidas. En este sistema, una LDR representa la iluminación ambiental y el LED representa una lámpara regulable.

Relación inversa

Con el divisor 5 V → LDR → A0 → 10 kΩ → GND, más luz produce lectura mayor. map(nivelLuz, 0, 1023, 255, 0) invierte el intervalo: una lectura baja solicita brillo alto. constrain() mantiene el valor dentro de 0–255.

No todo es encendido o apagado

El control por umbral elige dos estados. PWM permite niveles intermedios. En ambos casos necesitas comprobar las lecturas; la LDR no garantiza alcanzar exactamente 0 o 1023 en todos los montajes.

Prácticas

Lámpara que se adapta

  1. Construye el divisor de LDR de la semana 4 y conecta un LED a D9.
  2. Carga el ejemplo y mueve progresivamente el control de luz.
  3. Registra al menos cinco pares de lectura y PWM; explica la tendencia.

Resultado esperado: El brillo aumenta al disminuir la luz.

Código Arduino

const int pinLDR = A0;
const int pinLED = 9;
int nivelLuz = 0;
int brilloLED = 0;
void setup() {
  pinMode(pinLED, OUTPUT);
  Serial.begin(9600);
}
void loop() {
  // Leer el nivel de iluminación.
  nivelLuz = analogRead(pinLDR);
  // Convertir e invertir los intervalos.
  brilloLED = map(nivelLuz, 0, 1023, 255, 0);
  brilloLED = constrain(brilloLED, 0, 255);
  // Aplicar el brillo mediante PWM.
  analogWrite(pinLED, brilloLED);
  // Mostrar datos para verificar.
  Serial.print("LDR: ");
  Serial.print(nivelLuz);
  Serial.print(" | PWM: ");
  Serial.print(brilloLED);
  Serial.print(" | Estado: ");
  if (brilloLED > 170) {
    Serial.println("iluminacion alta");
  } else if (brilloLED > 80) {
    Serial.println("iluminacion media");
  } else {
    Serial.println("iluminacion baja");
  }
  delay(300);
}

Preguntas de repaso

1. ¿Qué relación necesita la lámpara automática?

  1. Más luz ambiental, más brillo siempre
  2. Menos luz ambiental, más brillo
  3. El brillo no cambia

2. ¿Qué hace constrain(brillo, 0, 255)?

  1. Limita el valor al intervalo permitido
  2. Convierte a °C
  3. Abre la puerta

3. ¿Qué diferencia principal tiene PWM respecto a un umbral binario?

  1. Permite niveles intermedios de salida
  2. Evita usar un sensor
  3. Solo funciona con PIR

Respuestas explicadas

1. Menos luz ambiental, más brillo. La lámpara compensa la disminución de luz ambiental.

2. Limita el valor al intervalo permitido. constrain() impide que el valor quede fuera del rango definido.

3. Permite niveles intermedios de salida. PWM modifica el ciclo de trabajo y permite graduar la respuesta.
