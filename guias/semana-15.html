Control de acceso: detectar y autorizar

Abre una puerta solo si coinciden dos condiciones.

¿Qué aprenderás?

  • Separar presencia y autorización.
  • Aplicar el operador &&.
  • Probar todas las combinaciones de entradas.

Dos preguntas diferentes

El PIR responde si su señal detecta movimiento; el pulsador representa una autorización. La puerta se abre únicamente si hay presencia y el botón está presionado. El prototipo no identifica personas.

Combinar con AND

La expresión presencia == HIGH && autorizacion == LOW exige ambas condiciones. LOW corresponde al botón conectado a GND con INPUT_PULLUP. Cambiar && por || modificaría la regla del acceso.

Esperar, permitir o solicitar

Sin presencia, el sistema espera. Con presencia sin autorización, mantiene la puerta cerrada y señaliza. Con ambas condiciones, abre a 90°. Una tabla de verdad ayuda a verificar los cuatro casos posibles.

Prácticas

Puerta con autorización

  1. Conecta los dos sensores de entrada y los actuadores de la tabla.
  2. Carga el programa y ejecuta las cuatro combinaciones.
  3. Explica por qué pulsar sin presencia no debe abrir según esta regla.

Resultado esperado: La puerta solo abre cuando presencia y autorización coinciden.

Código Arduino

#include <Servo.h>
Servo puerta;
const int pinPIR = 2;
const int pinBoton = 3;
const int ledVerde = 4;
const int ledRojo = 5;
const int pinBuzzer = 8;
const int pinServo = 9;
void setup() {
  pinMode(pinPIR, INPUT);
  pinMode(pinBoton, INPUT_PULLUP);
  pinMode(ledVerde, OUTPUT);
  pinMode(ledRojo, OUTPUT);
  pinMode(pinBuzzer, OUTPUT);
  puerta.attach(pinServo);
  puerta.write(0);
  Serial.begin(9600);
}
void loop() {
  int presencia = digitalRead(pinPIR);
  int autorizacion = digitalRead(pinBoton);
  if (presencia == HIGH && autorizacion == LOW) {
    puerta.write(90);
    digitalWrite(ledVerde, HIGH);
    digitalWrite(ledRojo, LOW);
    tone(pinBuzzer, 1500);
    Serial.println("ACCESO PERMITIDO");
  } else if (presencia == HIGH) {
    puerta.write(0);
    digitalWrite(ledVerde, LOW);
    digitalWrite(ledRojo, HIGH);
    tone(pinBuzzer, 400);
    Serial.println("ACCESO PENDIENTE");
  } else {
    puerta.write(0);
    digitalWrite(ledVerde, LOW);
    digitalWrite(ledRojo, LOW);
    noTone(pinBuzzer);
    Serial.println("SISTEMA EN ESPERA");
  }
  delay(200);
}

Preguntas de repaso

1. ¿Qué exige el operador &&?

  1. Al menos una condición
  2. Que se cumplan ambas condiciones
  3. Que ninguna se cumpla

2. ¿El PIR identifica al estudiante autorizado?

  1. Sí
  2. No
  3. Solo con Serial

3. ¿Qué pasa con botón pulsado pero sin presencia?

  1. La puerta abre siempre
  2. La puerta permanece cerrada
  3. El motor cambia de color

Respuestas explicadas

1. Que se cumplan ambas condiciones. AND solo es verdadero cuando sus dos operandos son verdaderos.

2. No. El PIR detecta cambios asociados al movimiento, no identidad.

3. La puerta permanece cerrada. La regla de apertura exige también presencia.
