Motor DC y ventilador automático

Controla una carga con una etapa de potencia y PWM.

¿Qué aprenderás?

  • Reconocer por qué un motor necesita una etapa de potencia.
  • Conectar tierras comunes y diodo de protección.
  • Elegir velocidad según temperatura.

Separar control y potencia

Un pin de Arduino no debe alimentar directamente un motor. El pin controla un transistor o driver y una fuente adecuada entrega la corriente del motor. En esta práctica se usa un TIP120 con resistencia de base y un diodo en paralelo al motor.

Conexión del motor

Conecta el emisor del TIP120 a GND común, el colector al terminal negativo del motor y el positivo a la fuente del motor. El diodo se coloca con cátodo al positivo del motor y ánodo al colector. Verifica los terminales del transistor antes de montar.

Tres niveles de ventilación

El ejemplo usa motor apagado bajo 25 °C, PWM 150 entre 25 y 30 °C inclusive, y PWM 255 por encima de 30 °C. Es un control por niveles; el valor PWM no es una medición directa de revoluciones por minuto.

Prácticas

Ventilador por temperatura

  1. Arma primero la etapa TIP120, resistencia de 1 kΩ, diodo y motor con su fuente.
  2. Conecta TMP36 y carga el ejemplo.
  3. Prueba 20, 27 y 35 °C y compara temperatura con PWM.

Resultado esperado: El motor pasa por apagado, nivel medio y nivel alto.

Código Arduino

const int pinTMP36 = A0;
const int pinMotor = 5;

int lectura = 0;
int pwmMotor = 0;
float voltaje = 0.0;
float temperatura = 0.0;

void setup() {
  pinMode(pinMotor, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  // Leer el sensor y convertir la lectura a grados Celsius.
  lectura = analogRead(pinTMP36);
  voltaje = lectura * (5.0 / 1023.0);
  temperatura = (voltaje - 0.5) * 100.0;

  // Seleccionar la velocidad según la temperatura.
  if (temperatura < 25.0) {
    pwmMotor = 0;
  } else if (temperatura <= 30.0) {
    pwmMotor = 150;
  } else {
    pwmMotor = 255;
  }

  // Aplicar el valor PWM al transistor que controla el motor.
  analogWrite(pinMotor, pwmMotor);

  // Mostrar información para comprobar el sistema.
  Serial.print("Temperatura: ");
  Serial.print(temperatura, 1);
  Serial.print(" °C | Estado: ");

  if (pwmMotor == 0) {
    Serial.print("apagado");
  } else if (pwmMotor == 150) {
    Serial.print("velocidad media");
  } else {
    Serial.print("velocidad alta");
  }

  Serial.print(" | PWM: ");
  Serial.println(pwmMotor);
  delay(500);
}

Preguntas de repaso

1. ¿Por qué se usa un transistor o driver?

  1. Para que el pin no alimente directamente la corriente del motor
  2. Para evitar programar
  3. Para medir la distancia

2. ¿Qué protege frente al transitorio inductivo del motor?

  1. El sensor PIR
  2. El diodo correctamente orientado
  3. El nombre de la variable

3. ¿Qué hace el ejemplo a 27 °C?

  1. Apaga el motor
  2. Aplica PWM 150
  3. Aplica PWM 255

Respuestas explicadas

1. Para que el pin no alimente directamente la corriente del motor. El pin entrega la señal de control y la etapa de potencia maneja la carga.

2. El diodo correctamente orientado. El diodo proporciona un camino para la corriente inductiva al desconectar la carga.

3. Aplica PWM 150. 27 °C pertenece al intervalo de 25 a 30 °C.
