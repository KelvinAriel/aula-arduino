TMP36: medir la temperatura

Del voltaje a los grados Celsius y a una alarma térmica.

¿Qué aprenderás?

  • Distinguir lectura, voltaje y temperatura.
  • Aplicar la conversión del TMP36.
  • Definir intervalos para señalizar estados térmicos.

Una señal proporcional a la temperatura

El TMP36 es un sensor analógico. Su salida tiene un desplazamiento de 0,5 V a 0 °C y aumenta unos 0,01 V por grado Celsius. A 25 °C produce aproximadamente 0,75 V. La fórmula utilizada en el ejemplo es específica de TMP36, no de cualquier sensor.

La conversión paso a paso

Con referencia nominal de 5 V: voltaje = lectura × 5,0 / 1023,0; después temperatura = (voltaje − 0,5) × 100. La lectura tiene resolución y tolerancias: un resultado cercano al límite puede fluctuar.

Interpretar con intervalos

Un semáforo térmico divide la temperatura en estados. Define qué intervalo incluye cada límite para no dejar huecos. Para una alarma a partir de 30 °C, compara con >= 30 y apágala en el caso contrario.

Prácticas

Termómetro digital

  1. Identifica alimentación, salida y GND usando las etiquetas del TMP36 en Tinkercad.
  2. Carga el ejemplo y abre Serial a 9600 baudios.
  3. Prueba 20, 29 y 35 °C; compara sensor, voltaje y temperatura calculada.

Resultado esperado: Serial muestra grados Celsius y el buzzer se activa desde el umbral.

Semáforo y alarma térmica

  1. Define tres intervalos sin solapamientos para LEDs verde, amarillo y rojo.
  2. Escribe las condiciones y prueba un valor interior y los límites de cada intervalo.
  3. Explica cómo una pequeña histéresis podría reducir cambios repetitivos alrededor del umbral.

Resultado esperado: Una tabla de estados y resultados observados.

Código Arduino

// TMP36: revisar las etiquetas de alimentacion, salida y GND.
const int pinTMP36 = A0, pinLED = 4, buzzer = 8;
const float umbral = 30.0;
void setup() {
  pinMode(pinLED, OUTPUT); pinMode(buzzer, OUTPUT);
  Serial.begin(9600);
}
void loop() {
  int lectura = analogRead(pinTMP36);
  float voltaje = lectura * (5.0 / 1023.0);
  float temperatura = (voltaje - 0.5) * 100.0;
  bool alerta = temperatura >= umbral;
  digitalWrite(pinLED, alerta ? HIGH : LOW);
  if (alerta) tone(buzzer, 1000);
  else noTone(buzzer);
  Serial.print("Temperatura (C): ");
  Serial.println(temperatura, 1);
  delay(300);
}

Preguntas de repaso

1. ¿Qué fórmula corresponde al TMP36?

  1. T = voltaje × 100
  2. T = (voltaje − 0,5) × 100
  3. T = lectura / 100

2. ¿Qué representa analogRead(A0)?

  1. Grados Celsius directos
  2. Un valor digital proporcional al voltaje
  3. La velocidad del motor

3. ¿Qué prueba conviene hacer además de un valor normal?

  1. Solo cambiar el color del cable
  2. Probar valores cercanos a los límites de cada intervalo
  3. Borrar Serial

Respuestas explicadas

1. T = (voltaje − 0,5) × 100. Se resta el desplazamiento de 0,5 V y se aplica la escala de 10 mV/°C.

2. Un valor digital proporcional al voltaje. La conversión a temperatura se realiza después de calcular el voltaje.

3. Probar valores cercanos a los límites de cada intervalo. Los límites revelan errores de comparaciones e intervalos.
