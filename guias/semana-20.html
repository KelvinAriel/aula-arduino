Mecanismos y barrera robótica

Relaciona el giro del servo con el movimiento de una palanca.

¿Qué aprenderás?

  • Reconocer transmisión y transformación del movimiento.
  • Relacionar longitud de palanca y esfuerzo.
  • Comprobar el algoritmo de una barrera.

Del eje a la estructura

Ejes, palancas, ruedas, poleas y engranajes transmiten o transforman movimiento. En una barrera, el brazo puede funcionar como una palanca unida al eje del servomotor.

El mecanismo también importa

Un brazo más largo recorre una distancia mayor en su extremo, pero una carga situada más lejos exige mayor par. El modelo digital del servo no garantiza que un brazo físico pueda moverse con cualquier longitud o peso.

La regla de la barrera

Con una distancia válida de 20 cm o menos se abre a 90°. Más lejos permanece a 0°. Si no llega una lectura válida, se cierra y señala error. La simulación representa el control; no reproduce todos los esfuerzos mecánicos.

Prácticas

Barrera por proximidad

  1. Dibuja la base, eje, brazo y dos posiciones de la barrera.
  2. Arma el circuito con servo, HC-SR04, LEDs y buzzer.
  3. Prueba 10, 20 y 40 cm y describe la respuesta ante error.

Resultado esperado: La barrera abre solo con objeto cercano y lectura válida.

Código Arduino

#include <Servo.h>
const int pinTrig = 9;
const int pinEcho = 10;
const int pinServo = 6;
const int ledVerde = 3;
const int ledRojo = 4;
const int buzzer = 8;
Servo barrera;
float medirDistancia() {
  digitalWrite(pinTrig, LOW);
  delayMicroseconds(2);
  digitalWrite(pinTrig, HIGH);
  delayMicroseconds(10);
  digitalWrite(pinTrig, LOW);
  unsigned long duracion = pulseIn(pinEcho, HIGH, 30000);
  if (duracion == 0) return -1.0;
  return duracion * 0.0343 / 2.0;
}
void cerrarBarrera() {
  barrera.write(0);
  digitalWrite(ledVerde, LOW);
  digitalWrite(ledRojo, HIGH);
}
void abrirBarrera() {
  barrera.write(90);
  digitalWrite(ledVerde, HIGH);
  digitalWrite(ledRojo, LOW);
}
void setup() {
  pinMode(pinTrig, OUTPUT);
  pinMode(pinEcho, INPUT);
  pinMode(ledVerde, OUTPUT);
  pinMode(ledRojo, OUTPUT);
  pinMode(buzzer, OUTPUT);
  barrera.attach(pinServo);
  cerrarBarrera();
  Serial.begin(9600);
}
void loop() {
  float distancia = medirDistancia();
  if (distancia < 0) {
    cerrarBarrera();
    tone(buzzer, 300);
    Serial.println("ERROR DE LECTURA");
  } else if (distancia <= 20) {
    abrirBarrera();
    tone(buzzer, 1200, 120);
    Serial.println("OBJETO DETECTADO - BARRERA ABIERTA");
  } else {
    cerrarBarrera();
    noTone(buzzer);
    Serial.println("BARRERA CERRADA");
  }
  delay(300);
}

Preguntas de repaso

1. ¿Qué elemento puede transmitir el giro del servo al brazo?

  1. Una palanca conectada al eje
  2. Un sensor TMP36
  3. Un archivo de texto

2. Según esta regla, a 20 cm la barrera…

  1. Se abre
  2. Permanece cerrada
  3. Se desconecta

3. Con igual carga, al alejarla más del eje…

  1. Se requiere mayor par
  2. Desaparece el esfuerzo
  3. Se mide más luz

Respuestas explicadas

1. Una palanca conectada al eje. La unión mecánica transmite el movimiento del eje.

2. Se abre. El intervalo de apertura incluye 20 cm.

3. Se requiere mayor par. El par depende de la fuerza y de la distancia al eje.
