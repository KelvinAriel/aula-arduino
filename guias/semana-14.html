Temperatura y ventilación coordinada

Combina motor, compuerta y señalización por intervalos.

¿Qué aprenderás?

  • Aplicar tres intervalos de temperatura.
  • Coordinar PWM y ángulo.
  • Comprobar límites y estados.

Una entrada, varias salidas

La temperatura puede controlar simultáneamente ventilador, compuerta e indicadores. Define una tabla de decisiones antes de programar para que todas las salidas representen el mismo estado.

Los límites de esta práctica

Bajo 24 °C: motor apagado y compuerta a 0°. De 24 a 30 °C inclusive: PWM 150 y 45°. Por encima de 30 °C: PWM 255 y 90°. Estos intervalos difieren de la semana 10; se deben usar los de la práctica actual.

Prueba y estabilidad

Una temperatura cercana al umbral puede provocar cambios repetitivos. Registra esa posibilidad y diseña después una histéresis: diferentes límites para pasar a un estado y para regresar. El ejemplo base utiliza comparaciones directas.

Prácticas

Ventilación con compuerta

  1. Arma motor con etapa de potencia, TMP36, servo y LEDs.
  2. Carga el programa y prueba 20, 27 y 35 °C.
  3. Revisa valores cercanos a 24 y 30 °C y registra motor, ángulo e indicadores.

Resultado esperado: Las salidas siguen una misma tabla de estado.

Código Arduino

#include <Servo.h>
Servo compuerta;
const int pinTMP36 = A0;
const int ledVerde = 3;
const int ledRojo = 4;
const int pinMotor = 5;
const int pinServo = 9;
void setup() {
  pinMode(ledVerde, OUTPUT);
  pinMode(ledRojo, OUTPUT);
  pinMode(pinMotor, OUTPUT);
  compuerta.attach(pinServo);
  compuerta.write(0);
  Serial.begin(9600);
}
void loop() {
  int lectura = analogRead(pinTMP36);
  float voltaje = lectura * (5.0 / 1023.0);
  float temperatura = (voltaje - 0.5) * 100.0;
  int pwmMotor;
  int anguloCompuerta;
  if (temperatura < 24.0) {
    pwmMotor = 0;
    anguloCompuerta = 0;
    digitalWrite(ledVerde, HIGH);
    digitalWrite(ledRojo, LOW);
    Serial.print("NORMAL");
  } else if (temperatura <= 30.0) {
    pwmMotor = 150;
    anguloCompuerta = 45;
    digitalWrite(ledVerde, LOW);
    digitalWrite(ledRojo, LOW);
    Serial.print("VENTILACION MEDIA");
  } else {
    pwmMotor = 255;
    anguloCompuerta = 90;
    digitalWrite(ledVerde, LOW);
    digitalWrite(ledRojo, HIGH);
    Serial.print("VENTILACION ALTA");
  }
  analogWrite(pinMotor, pwmMotor);
  compuerta.write(anguloCompuerta);
  Serial.print(" | Temperatura: ");
  Serial.print(temperatura, 1);
  Serial.print(" °C | PWM: ");
  Serial.print(pwmMotor);
  Serial.print(" | Angulo: ");
  Serial.println(anguloCompuerta);
  delay(500);
}

Preguntas de repaso

1. ¿Cuál es la respuesta a 27 °C en esta semana?

  1. Motor apagado y 0°
  2. PWM 150 y 45°
  3. PWM 255 y 90°

2. ¿Por qué documentar los límites?

  1. Para que todas las salidas usen los mismos estados
  2. Para reducir el número de cables a cero
  3. Para omitir pruebas

3. ¿Qué puede reducir cambios repetidos cerca del umbral?

  1. Una histéresis bien definida
  2. Un nombre más largo
  3. Invertir todos los LEDs

Respuestas explicadas

1. PWM 150 y 45°. 27 °C se encuentra dentro de la banda media de 24 a 30 °C.

2. Para que todas las salidas usen los mismos estados. La tabla evita decisiones contradictorias entre motor, servo y LEDs.

3. Una histéresis bien definida. La histéresis usa límites distintos para cambiar y regresar de estado.
