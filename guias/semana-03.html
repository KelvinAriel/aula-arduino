Distancia, luz y temperatura

Repasa tres proyectos y su relación con la manufactura digital.

¿Qué aprenderás?

  • Convertir una medición en una respuesta.
  • Relacionar analogRead() con PWM.
  • Reconocer el flujo del modelo 3D a la fabricación.

Tres sensores, diferentes señales

El HC-SR04 calcula distancia a partir del tiempo de un eco. La LDR se conecta con una resistencia fija como divisor de tensión. El TMP36 entrega un voltaje que se convierte en grados Celsius; su lectura analógica no es directamente una temperatura.

Leer no es lo mismo que escribir

En el UNO R3, analogRead() devuelve normalmente 0 a 1023. analogWrite() utiliza 0 a 255 en pines PWM. map() ayuda a transformar un intervalo en otro. El brillo deseado puede aumentar cuando disminuye la luz: eso requiere invertir la relación.

Del circuito al prototipo

Una solución también necesita una estructura física. La manufactura aditiva construye capa por capa a partir de un modelo digital. El flujo de trabajo incluye modelar, exportar, laminar, fabricar y probar; exportar STL no sustituye la preparación del laminador.

Código Arduino

// Semaforo de proximidad: el error no se interpreta como camino libre.
const int pinTrig = 9, pinEcho = 10;
const int ledVerde = 4, ledAmarillo = 5, ledRojo = 6;

float medirDistancia() {
  digitalWrite(pinTrig, LOW);
  delayMicroseconds(2);
  digitalWrite(pinTrig, HIGH);
  delayMicroseconds(10);
  digitalWrite(pinTrig, LOW);
  unsigned long duracion = pulseIn(pinEcho, HIGH, 30000);
  if (duracion == 0) return -1.0;
  return duracion * 0.0343 / 2.0;
}
void setup() {
  pinMode(pinTrig, OUTPUT); pinMode(pinEcho, INPUT);
  pinMode(ledVerde, OUTPUT); pinMode(ledAmarillo, OUTPUT);
  pinMode(ledRojo, OUTPUT);
  Serial.begin(9600);
}
void loop() {
  float distancia = medirDistancia();
  bool valida = distancia >= 0;
  digitalWrite(ledRojo, valida && distancia <= 30 ? HIGH : LOW);
  digitalWrite(ledAmarillo, valida && distancia > 30 && distancia <= 100 ? HIGH : LOW);
  digitalWrite(ledVerde, valida && distancia > 100 ? HIGH : LOW);
  if (valida) {
    Serial.print("Distancia (cm): ");
    Serial.println(distancia, 1);
  } else {
    Serial.println("ERROR: sin eco valido");
  }
  delay(300);
}

Preguntas de repaso

1. ¿Por qué se divide entre dos al calcular distancia con el eco?

  1. Porque el sonido recorre ida y vuelta
  2. Porque hay dos LEDs
  3. Porque Arduino solo cuenta pares

2. ¿Cuál es el intervalo habitual de analogRead() en UNO R3?

  1. 0 a 255
  2. 0 a 1023
  3. 1 a 100

3. ¿Qué hace un laminador?

  1. Mide el PIR
  2. Prepara capas e instrucciones de fabricación
  3. Convierte luz en voltaje

Respuestas explicadas

1. Porque el sonido recorre ida y vuelta. El tiempo corresponde al viaje desde el sensor al objeto y de regreso.

2. 0 a 1023. Su convertidor analógico a digital es de 10 bits.

3. Prepara capas e instrucciones de fabricación. El laminador transforma la geometría y los parámetros elegidos en instrucciones para la impresora.
