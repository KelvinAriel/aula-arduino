Primero el problema y las reglas

El contenedor detecta presencia, estima espacio disponible y mueve una tapa simulada. Un algoritmo define el orden de lectura y las decisiones antes de escribir instrucciones específicas de Arduino.

La distancia representa espacio libre

Con el sensor orientado hacia el contenido, distancia mayor de 25 cm representa disponible; mayor de 10 y hasta 25 cm, nivel medio; 10 cm o menos, lleno. Una menor distancia significa que el contenido está más cerca del sensor.

Prioridades del sistema

Con lectura inválida la tapa permanece cerrada y se señala error. Con estado lleno tampoco abre. Solo abre si hay presencia, lectura válida y espacio. Los valores son una simplificación didáctica, no una medición calibrada de porcentaje de llenado.

Prácticas

Diseña y construye el contenedor

  1. Escribe el pseudocódigo y predice seis escenarios, incluido error.
  2. Conecta los módulos y prueba primero el sensor de distancia.
  3. Carga el programa y verifica las prioridades del algoritmo.

Resultado esperado: La tapa abre con presencia y espacio; permanece cerrada si está lleno o falla la medición.

Código Arduino

#include <Servo.h>
const int pinPir = 2;
const int ledVerde = 3;
const int ledAmarillo = 4;
const int ledRojo = 5;
const int pinServo = 6;
const int pinBuzzer = 8;
const int pinTrig = 9;
const int pinEcho = 10;
Servo tapa;
float medirDistancia();
void mostrarNivel(int verde, int amarillo, int rojo);
void setup() {
  pinMode(pinPir, INPUT);
  pinMode(ledVerde, OUTPUT);
  pinMode(ledAmarillo, OUTPUT);
  pinMode(ledRojo, OUTPUT);
  pinMode(pinBuzzer, OUTPUT);
  pinMode(pinTrig, OUTPUT);
  pinMode(pinEcho, INPUT);
  tapa.attach(pinServo);
  tapa.write(0);
  Serial.begin(9600);
}
void loop() {
  float distancia = medirDistancia();
  int presencia = digitalRead(pinPir);
  bool lecturaValida = distancia >= 0.0;
  bool lleno = false;
  const char* nivel = "ERROR";
  if (!lecturaValida) {
    mostrarNivel(LOW, LOW, LOW);
    tone(pinBuzzer, 300);
    tapa.write(0);
    Serial.print("SIN LECTURA VALIDA");
  } else {
    if (distancia <= 10.0) {
      lleno = true;
      nivel = "LLENO";
      mostrarNivel(LOW, LOW, HIGH);
      tone(pinBuzzer, 1000);
    } else if (distancia <= 25.0) {
      nivel = "MEDIO";
      mostrarNivel(LOW, HIGH, LOW);
      noTone(pinBuzzer);
    } else {
      nivel = "DISPONIBLE";
      mostrarNivel(HIGH, LOW, LOW);
      noTone(pinBuzzer);
    }
    if (presencia == HIGH && !lleno) {
      tapa.write(90);
    } else {
      tapa.write(0);
    }
    Serial.print("Distancia: ");
    Serial.print(distancia, 1);
    Serial.print(" cm | Nivel: ");
    Serial.print(nivel);
  }
  Serial.print(" | Presencia: ");
  Serial.print(presencia);
  Serial.print(" | Tapa: ");
  if (lecturaValida && presencia == HIGH && !lleno) {
    Serial.println("ABIERTA");
  } else {
    Serial.println("CERRADA");
  }
  delay(300);
}
float medirDistancia() {
  digitalWrite(pinTrig, LOW);
  delayMicroseconds(2);
  digitalWrite(pinTrig, HIGH);
  delayMicroseconds(10);
  digitalWrite(pinTrig, LOW);
  unsigned long duracion = pulseIn(pinEcho, HIGH, 30000);
  if (duracion == 0) {
    return -1.0;
  }
  return duracion * 0.0343 / 2.0;
}
void mostrarNivel(int verde, int amarillo, int rojo) {
  digitalWrite(ledVerde, verde);
  digitalWrite(ledAmarillo, amarillo);
  digitalWrite(ledRojo, rojo);
}

Preguntas de repaso

1. ¿Qué representa una distancia menor en este montaje?

  1. Más espacio libre
  2. Contenido más cerca del sensor
  3. Menos temperatura

2. Con 8 cm y presencia, ¿qué debe ocurrir?

  1. Abrir siempre
  2. Mantener cerrada la tapa y avisar lleno
  3. Apagar Arduino

3. ¿Qué conviene definir antes de programar?

  1. Requisitos, estados y pruebas
  2. Solo el color de la carcasa
  3. La nota final

Respuestas explicadas

1. Contenido más cerca del sensor. El sensor mira hacia el contenido; al llenarse disminuye el espacio medido.

2. Mantener cerrada la tapa y avisar lleno. El estado lleno tiene prioridad sobre la presencia.

3. Requisitos, estados y pruebas. Esas definiciones permiten comprobar si el código cumple el problema.
