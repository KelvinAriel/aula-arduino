Servomotor y puerta automática

Controla una posición angular a partir de una entrada PIR.

¿Qué aprenderás?

  • Distinguir servo y motor DC.
  • Usar attach() y write().
  • Explicar el efecto de delay() en la respuesta.

Controlar una posición

Un servomotor de posición recibe órdenes de ángulo dentro de su recorrido admitido. No se comporta como un motor DC de giro continuo. En el modelo de esta práctica, 0° representa puerta cerrada y 90° puerta abierta.

La biblioteca Servo

Incluye Servo.h, crea un objeto, asocia el pin de señal con attach(9) y solicita una posición con write(). La señal del servo se genera mediante la biblioteca; no necesitas usar analogWrite() para ordenar el ángulo.

Una pausa que detiene lecturas

El programa abre la puerta, espera tres segundos y la cierra. Durante delay(3000), no lee nuevamente el PIR. Si necesitas responder a otros sensores mientras espera, diseña un control de tiempo con millis().

Prácticas

Puerta activada por PIR

  1. Conecta OUT del PIR a D4 y señal del servo a D9.
  2. Carga el programa y simula movimiento.
  3. Describe la apertura, la espera y el cierre; verifica qué pasa si la señal sigue activa.

Resultado esperado: La puerta abre a 90°, espera tres segundos y vuelve a 0°; puede repetir el ciclo si el PIR sigue activo.

Ten en cuenta: En UNO R3, Servo ocupa un temporizador que afecta PWM en D9 y D10. Para combinar servo con brillo o motor PWM utiliza otros pines apropiados.

Código Arduino

#include <Servo.h>

// Objeto que permite controlar el servomotor
Servo puerta;

// Pines utilizados en el circuito
const int pinPIR = 4;
const int pinServo = 9;

// Variable para guardar el estado del sensor PIR
int estadoPIR = LOW;

void setup() {
  pinMode(pinPIR, INPUT);       // D4 recibe la señal digital del PIR
  puerta.attach(pinServo);     // La señal del servo está conectada a D9
  puerta.write(0);             // La puerta inicia cerrada
}

void loop() {
  estadoPIR = digitalRead(pinPIR);

  if (estadoPIR == HIGH) {
    puerta.write(90);          // Abre la puerta a 90 grados
    delay(3000);               // Permanece abierta durante 3 segundos
    puerta.write(0);           // Regresa a la posición cerrada
  } else {
    puerta.write(0);           // Sin movimiento, permanece cerrada
  }
}

Preguntas de repaso

1. ¿Qué indica puerta.write(90)?

  1. Una velocidad de 90 RPM
  2. Una posición solicitada de 90°
  3. Una espera de 90 segundos

2. ¿Qué hace attach(9)?

  1. Asocia el servo con su pin de señal
  2. Alimenta el motor desde nueve pines
  3. Lee temperatura

3. ¿Qué ocurre durante delay(3000)?

  1. loop continúa leyendo todos los sensores
  2. La ejecución normal espera tres segundos
  3. El servo pierde toda alimentación

Respuestas explicadas

1. Una posición solicitada de 90°. write() solicita una posición angular al servomotor.

2. Asocia el servo con su pin de señal. attach() establece el pin de control del objeto Servo.

3. La ejecución normal espera tres segundos. La pausa bloquea el avance del programa antes de la siguiente instrucción.
